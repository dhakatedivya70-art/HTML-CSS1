HTML Forms

💡 What is a Form?

An HTML form is used to collect user input. It can submit data to a server for processing using methods like GET or POST.

📌 Importance of Forms

  • Collect user information (name, email, feedback)
  • Enable user authentication (login/signup)
  • Supports surveys, polls, and registrations
  • Crucial for interactive web applications

📌 Common Form Elements

  • <form> – container for all form elements
  • <input> – different types of user input (text, email, password, number, radio, checkbox, date)
  • <textarea> – multi-line text input
  • <select> and <option> – dropdown menu
  • <button> – submit, reset, or custom actions
  • <label> – associate text with input for accessibility

📖 Example Form

<form action="/submit" method="post">
  <label for="name">Name:</label>
  <input type="text" id="name" name="name" placeholder="Enter your name" required>

  <label for="email">Email:</label>
  <input type="email" id="email" name="email" placeholder="Enter your email" required>

  <label for="gender">Gender:</label>
  <input type="radio" name="gender" value="Male"> Male
  <input type="radio" name="gender" value="Female"> Female

  <label for="hobby">Hobbies:</label>
  <input type="checkbox" name="hobby" value="Reading"> Reading
  <input type="checkbox" name="hobby" value="Sports"> Sports

  <label for="country">Country:</label>
  <select id="country" name="country">
    <option value="India">India</option>
    <option value="USA">USA</option>
  </select>

  <label for="message">Message:</label>
  <textarea id="message" name="message" rows="4" placeholder="Write your message"></textarea>

  <button type="submit">Submit</button>
</form>

🎯 Best Practices

  • Always use label for input fields for accessibility.
  • Use proper input types (email, number, date) for validation.
  • Use required attribute for mandatory fields.
  • Group radio buttons with the same name.
  • Use placeholder for hints, but not as a replacement for labels.
  • Keep forms concise and user-friendly.
