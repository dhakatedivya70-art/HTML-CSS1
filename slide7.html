HTML Lists

💡 What are HTML Lists?

Lists in HTML are used to display content in an organized manner. They help structure items clearly and can be styled using CSS.

📌 Types of Lists

  • Unordered List (<ul>) → Items are bulleted
  • Ordered List (<ol>) → Items are numbered or lettered
  • Definition List (<dl>) → List of terms and their definitions using <dt> and <dd>

📝 Syntax

<!-- Unordered List -->
<ul>
  <li>Item 1</li>
  <li>Item 2</li>
</ul>

<!-- Ordered List -->
<ol type="1">  <!-- type="1" for numbers, "A" for uppercase letters, "a" for lowercase, "I" or "i" for roman numerals -->
  <li>First</li>
  <li>Second</li>
</ol>

<!-- Definition List -->
<dl>
  <dt>HTML</dt>
  <dd>Hypertext Markup Language</dd>
  <dt>CSS</dt>
  <dd>Cascading Style Sheets</dd>
</dl>

📖 Examples

<!-- Unordered List Example -->
<ul>
  <li>Apples</li>
  <li>Oranges</li>
  <li>Bananas</li;
</ul>

<!-- Ordered List Example -->
<ol type="A" start="3">  <!-- starts with letter C -->
  <li>Chapter 1</li>
  <li>Chapter 2</li>
</ol>

<!-- Definition List Example -->
<dl>
  <dt>HTML</dt>
  <dd>Hypertext Markup Language - used to structure web content</dd>
  <dt>CSS</dt>
  <dd>Cascading Style Sheets - used for styling web pages</dd>
</dl>

🎯 Best Practices

  • Use lists to organize information clearly.
  • Prefer semantic HTML lists over manual bullet symbols or numbers.
  • Use type, start, and reversed attributes in <ol> for customization.
  • Use <dl> for key-value pairs like glossary terms.
  • Use CSS to style lists instead of inline symbols.
  • Keep lists concise and readable for better user experience.
