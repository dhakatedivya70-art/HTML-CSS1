HTML Labels

💡 What is a Label?

The <label> tag defines a label for an input element. It improves accessibility by allowing users to click on the label to focus on the input.

📌 Importance

  • Enhances form accessibility for screen readers
  • Improves user experience by linking text to input
  • Helps in better form design and usability

📌 Ways to Use Labels

  • Using for attribute: Connects label to input by input's id
  • Wrapping input inside label: No need for for, input is automatically associated

📖 Example: Label with Text, Checkbox & Radio

<form>

  <!-- Text Input with for attribute -->
  <label for="username">Username:</label>
  <input type="text" id="username" name="username">

  <!-- Checkbox with wrapping label -->
  <label>
    <input type="checkbox" name="subscribe"> Subscribe to newsletter
  </label>

  <!-- Radio with for attribute -->
  <input type="radio" id="male" name="gender" value="Male">
  <label for="male">Male</label>

  <input type="radio" id="female" name="gender" value="Female">
  <label for="female">Female</label>

</form>

🎯 Best Practices

  • Always use label for better accessibility
  • Prefer for attribute when possible for clarity
  • Ensure label text is descriptive and clear
  • Combine labels with placeholders for better UX
