The HTML <p> Tag

💡 What is the <p> Tag?

The <p> tag defines a paragraph in HTML. It is used to group together sentences or content to create readable blocks of text.

📝 Syntax

<p>Your paragraph text goes here.</p>

Every paragraph starts with <p> and ends with </p>.

📖 Example

<!DOCTYPE html>
<html>
  <head>
    <title>Paragraph Example</title>
  </head>
  <body>
    <h1>My First Web Page</h1>
    <p>This is a simple paragraph of text.</p>
    <p>You can write multiple paragraphs to separate content.</p>
  </body>
</html>

🎯 Best Practices

  • Use a separate <p> tag for each paragraph.
  • Don’t put headings or block elements inside a paragraph.
  • Keep your text readable and properly structured.
  • Use semantic paragraphs instead of multiple <br> for spacing.
