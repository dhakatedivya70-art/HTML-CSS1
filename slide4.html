HTML Headings

💡 What are Headings?

Heading tags are used to define titles and subtitles on a webpage. They range from <h1> (most important) to <h6> (least important).

📏 Heading Sizes

  • <h1> → Largest, main page title (~32px)
  • <h2> → Section title (~24px)
  • <h3> → Subsection heading (~20px)
  • <h4> → Smaller heading (~16px)
  • <h5> → Even smaller (~14px)
  • <h6> → Smallest heading (~12px)

📝 Syntax

<h1>Main Heading</h1>
<h2>Section Title</h2>
<h3>Subsection</h3>
...
<h6>Smallest Heading</h6>

📖 Example

<!DOCTYPE html>
<html>
  <head>
    <title>Heading Example</title>
  </head>
  <body>
    <h1>Website Title</h1>        <!-- 32px -->
    <h2>Section Title</h2>        <!-- 24px -->
    <h3>Subsection</h3>          <!-- 20px -->
    <h4>Minor Section</h4>       <!-- 16px -->
    <h5>Small Heading</h5>       <!-- 14px -->
    <h6>Tiny Heading</h6>        <!-- 12px -->
    <p>This is a paragraph under the subheading.</p>
  </body>
</html>

🎯 Why Only One H1?

  • SEO: Search engines recognize H1 as the main topic of the page.
  • Accessibility: Screen readers use H1 to identify main page content.
  • Structure: Helps maintain proper hierarchical content flow.

🎯 Best Practices

  • Use one <h1> per page (main heading).
  • Follow proper hierarchy: h1 → h2 → h3 …
  • Keep headings concise, meaningful, and descriptive.
  • Use headings to improve readability, SEO, and accessibility.
