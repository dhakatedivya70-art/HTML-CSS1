HTML Semantic Elements

💡 What are Semantic Elements?

Semantic elements clearly describe their meaning and purpose in the code, making it easier for browsers, developers, and search engines to understand.

📌 Importance

  • Improves accessibility for screen readers
  • Better SEO as search engines understand page structure
  • Enhances code readability and maintainability

📌 Common Semantic Tags

  • <header> – Page or section header
  • <footer> – Page or section footer
  • <main> – Main content of the page
  • <article> – Independent content like blog post
  • <section> – Thematic grouping of content
  • <aside> – Sidebar or related info
  • <nav> – Navigation links

📖 Example Structure

<!DOCTYPE html>
<html lang="en">
<body>

  <header>
    <h1>Website Title</h1>
    <nav>
      <a href="#">Home</a>
      <a href="#">About</a>
    </nav>
  </header>

  <main>
    <article>
      <h2>Blog Post</h2>
      <p>Content goes here...</p>
    </article>

    <section>
      <h2>Services</h2>
      <p>Service details...</p>
    </section>

    <aside>
      <p>Related info or sidebar content</p>
    </aside>
  </main>

  <footer>
    <p>© 2025 Your Company</p>
  </footer>

</body>
</html>

🎯 Best Practices

  • Use semantic tags instead of generic <div> and <span> whenever possible
  • Keep a consistent structure with header, main, and footer
  • Use <article> and <section> for logically grouped content
  • Use <aside> for related or secondary content
  • Semantic elements improve SEO and accessibility
