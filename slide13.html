HTML Form Validation

💡 What is Form Validation?

Form validation ensures that users enter correct and complete information before submitting a form. It prevents incorrect data from being sent to the server.

📌 Importance

  • Prevents incomplete or invalid data submission
  • Improves user experience by giving immediate feedback
  • Reduces server-side errors
  • Enhances security and data integrity

📌 HTML Validation Attributes

  • required – field must be filled
  • minlength – minimum number of characters
  • maxlength – maximum number of characters
  • pattern – regex pattern for allowed input
  • type – email, number, url, date, etc., for built-in validation
  • min / max – for number, date, and range inputs

📖 Example Form with Validation

<form action="/submit" method="post">
  <label>Username:</label>
  <input type="text" name="username" required minlength="3" maxlength="15">

  <label>Email:</label>
  <input type="email" name="email" required>

  <label>Password:</label>
  <input type="password" name="password" required pattern=".{6,}">

  <label>Age:</label>
  <input type="number" name="age" min="18" max="100" required>

  <label>Website:</label>
  <input type="url" name="website">

  <button type="submit">Submit</button>
</form>

🎯 Best Practices

  • Always use required for essential fields
  • Use minlength and maxlength for text inputs
  • Use pattern for format-specific inputs like passwords or phone numbers
  • Use proper type for built-in validation (email, url, number)
  • Combine client-side validation with server-side validation for security
  • Give clear error messages to guide users
