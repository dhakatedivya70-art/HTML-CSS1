Introduction to HTML

💡 What is HTML?

HTML stands for HyperText Markup Language. It is the standard language used to create web pages and web applications.

🌐 Purpose of HTML

  • Defines the structure of web pages.
  • Organizes content using tags and elements.
  • Works alongside CSS (for styling) and JavaScript (for interactivity).

🏗️ Example HTML Page

<!DOCTYPE html>
<html>
  <head>
    <title>My First Web Page</title>
  </head>
  <body>
    <h1>Welcome to HTML!</h1>
    <p>This is my first webpage.</p>
  </body>
</html>

📚 Key Points

  • HTML = Structure of the page
  • CSS = Styling & Layout
  • JavaScript = Interactivity
