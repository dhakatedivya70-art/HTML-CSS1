HTML Form Input Types

💡 Introduction

HTML input types define the type of data a user can enter into a form field. Using the correct input type helps with validation, user experience, and accessibility.

📌 Common Input Types

  • text – single-line text input
  • email – input for email addresses
  • password – hides user input for security
  • number – input for numeric values
  • date – input for selecting a date
  • time – input for time
  • url – input for web addresses
  • tel – input for phone numbers
  • color – input for selecting a color
  • range – slider input for numeric range
  • checkbox – multiple selection options
  • radio – single selection among options
  • file – upload file from user device
  • submit – submit form
  • reset – reset form values
  • button – custom button for JavaScript actions

📖 Example Form with Multiple Input Types

<form action="/submit" method="post">
  <label>Name:</label>
  <input type="text" name="name" required>

  <label>Email:</label>
  <input type="email" name="email" required>

  <label>Password:</label>
  <input type="password" name="password" required>

  <label>Age:</label>
  <input type="number" name="age" min="1" max="120">

  <label>Date of Birth:</label>
  <input type="date" name="dob">

  <label>Gender:</label>
  <input type="radio" name="gender" value="Male"> Male
  <input type="radio" name="gender" value="Female"> Female

  <label>Hobbies:</label>
  <input type="checkbox" name="hobby" value="Reading"> Reading
  <input type="checkbox" name="hobby" value="Sports"> Sports

  <label>Select Country:</label>
  <select name="country">
    <option>India</option>
    <option>USA</option>
  </select>

  <label>Upload File:</label>
  <input type="file" name="resume">

  <label>Pick Color:</label>
  <input type="color" name="color">

  <button type="submit">Submit</button>
</form>

🎯 Best Practices

  • Use proper input types to enable built-in validation
  • Always use label for accessibility
  • Set min/max values for number and range inputs
  • Use placeholder text as guidance, not replacement for labels
  • Group radio buttons with the same name attribute
  • Use required attribute for mandatory fields
