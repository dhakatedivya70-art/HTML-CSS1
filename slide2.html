HTML Structure

🧩 Basic HTML Document

Every HTML page follows a standard structure that organizes content for browsers.

<!DOCTYPE html>
<html>
  <head>
    <title>Page Title</title>
  </head>
  <body>
    <h1>Main Heading</h1>
    <p>This is a paragraph.</p>
  </body>
</html>

📖 Explanation of Tags

  • <!DOCTYPE html> → Declares document type and HTML version.
  • <html> → Root element of the webpage.
  • <head> → Contains metadata, links, and page title.
  • <title> → Sets the title shown in the browser tab.
  • <body> → Contains visible content like headings, paragraphs, images, and links.

🎯 Tips for HTML Structure

  • Always use proper indentation for readability.
  • Use semantic tags like <header>, <footer>, <section> for meaningful structure.
  • Close all tags properly to avoid rendering issues.
