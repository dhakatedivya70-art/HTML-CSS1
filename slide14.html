HTML Textarea, Select & Datalist

💡 Textarea

<textarea> is used for multi-line text input. You can control rows, columns, and placeholder text.

💡 Select & Option

<select> creates a dropdown menu, and <option> defines the selectable items.

💡 Datalist

<datalist> provides a list of predefined options for an input field. Users can type or select from suggestions.

📖 Example Form

<form action="/submit" method="post">

  <label>Message:</label>
  <textarea name="message" rows="4" placeholder="Enter your message"></textarea>

  <label>Choose a country:</label>
  <select name="country">
    <option>India</option>
    <option>USA</option>
    <option>UK</option>
  </select>

  <label>Favorite Browser:</label>
  <input list="browsers" name="browser" placeholder="Select or type browser">
  <datalist id="browsers">
    <option value="Chrome">
    <option value="Firefox">
    <option value="Safari">
    <option value="Edge">
  </datalist>

  <button type="submit">Submit</button>

</form>

🎯 Best Practices

  • Use rows and cols to control textarea size
  • Always include a label for accessibility
  • Use datalist for input suggestions to improve UX
  • Keep dropdown menus concise and organized
  • Combine placeholder text with label for clarity
