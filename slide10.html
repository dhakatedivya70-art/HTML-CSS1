HTML Tables

💡 What are HTML Tables?

HTML tables are used to organize data in rows and columns. They help display structured information, like schedules, pricing, or comparison charts.

📌 Table Elements

  • <table> – container for the table
  • <tr> – table row
  • <th> – table header cell (bold and centered by default)
  • <td> – table data cell
  • <caption> – optional title or description of the table

📌 Common Table Attributes

  • border – defines the border width of the table (deprecated, use CSS)
  • cellpadding – space between cell content and border (deprecated, use CSS padding)
  • cellspacing – space between cells (deprecated, use CSS border-spacing)
  • summary – description for accessibility (screen readers)
  • colspan – span a cell across multiple columns
  • rowspan – span a cell across multiple rows

📖 Example Table

<table border="1" cellpadding="8" cellspacing="4" summary="Student Grades">
  <caption>Student Marks</caption>
  <tr>
    <th>Name</th>
    <th>Math</th>
    <th>Science</th>
  </tr>
  <tr>
    <td>John</td>
    <td>90</td>
    <td>85</td>
  </tr>
  <tr>
    <td>Mary</td>
    <td>88</td>
    <td>92</td>
  </tr>
</table>

🎯 Best Practices

  • Use CSS instead of deprecated attributes for styling (borders, padding, spacing).
  • Always use <th> for header cells for accessibility.
  • Use caption to describe table content.
  • Use colspan and rowspan to merge cells logically.
  • Ensure tables are responsive for mobile devices using CSS.
