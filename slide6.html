HTML <img> Tag

💡 What is the <img> Tag?

The <img> tag is used to display images on a webpage. It is a self-closing tag (no separate closing tag) and is one of the most important elements for visual content in HTML.

📌 Importance of Images

  • Make webpages visually appealing and engaging.
  • Illustrate content for better understanding.
  • Enhance user experience and retention.
  • Can be used for logos, banners, icons, and media content.

📝 Syntax

<img src="image-url" alt="description" width="300" height="200" title="Image title" >

Attributes:

  • src → Path or URL of the image
  • alt → Text displayed if image fails to load (important for accessibility)
  • width → Width of the image in pixels
  • height → Height of the image in pixels
  • title → Tooltip text shown on hover

📖 Examples

<!-- Display a logo -->
<img src="logo.png" alt="Company Logo" width="150" height="80" title="Company Logo">

<!-- Display an external image -->
<img src="https://example.com/banner.jpg" alt="Website Banner" width="600" height="200">

<!-- Lazy loading image -->
<img src="photo.jpg" alt="Beautiful Landscape" loading="lazy">

<!-- Decorative image (alt empty for accessibility) -->
<img src="decorative.png" alt="">

🎯 Best Practices

  • Always provide alt text for accessibility and SEO.
  • Specify width and height to prevent layout shift.
  • Use optimized images to reduce page load time.
  • Use meaningful title when needed.
  • Use correct file formats (JPEG, PNG, WebP) depending on image type.
