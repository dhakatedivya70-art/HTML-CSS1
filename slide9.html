Nested Lists in HTML

💡 What are Nested Lists?

Nested lists are lists within lists. You can place a <ul> or <ol> inside a list item (<li>) to create hierarchy or sub-items.

📌 Importance & Use Cases

  • Organizes complex information hierarchically
  • Useful for menus, submenus, or multi-level item lists
  • Enhances readability and structured layout
  • Supports both ordered and unordered combinations

📝 Syntax

<ul>
  <li>Item 1
    <ul>
      <li>Subitem 1a</li>
      <li>Subitem 1b</li>
    </ul>
  </li>
  <li>Item 2</li>
</ul>

<ol>
  <li>Step 1
    <ol>
      <li>Substep 1a</li>
      <li>Substep 1b</li>
    </ol>
  </li>
  <li>Step 2</li>
</ol>

📖 Example – Mixed Nested List

<ul>
  <li>Fruits
    <ol>
      <li>Apple</li>
      <li>Orange</li>
    </ol>
  </li>
  <li>Vegetables
    <ul>
      <li>Carrot</li>
      <li>Broccoli</li>
    </ul>
  </li>
</ul>

This creates a hierarchical list combining ordered and unordered types.

🎯 Best Practices

  • Keep nesting to 2–3 levels to avoid clutter.
  • Maintain semantic HTML for accessibility.
  • Use CSS for indentation and styling instead of excessive nested lists.
  • Label sub-items clearly to avoid confusion.
